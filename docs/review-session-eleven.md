# Transfer release hardening review

A separate task reviewed the hardening and release changes without the implementation conversation. It inspected executable interruption and TLS tests, bounded-memory verification, product-specific packaging and provenance, exact-commit CI gates, stable download coexistence, native/cross-build scope and platform restrictions. It ran Go 1.27.3 repository-wide race tests and vet, twenty Python release guards, script compilation and native executable delivery/restart/interruption/TLS smoke. No blocking findings were found.

The review confirmed that development Transfer versions cannot publish, existing published Inspect tags are skipped and immutable, and either publisher carries the other product's complete five-archive set only after checksum validation. Both workflows use the same release concurrency group. Product tags and verification metadata stay separate. Windows checks explicitly cover version/help and unsupported-operation behavior, not file delivery. Linux amd64/macOS arm64 operational checks remain distinct from Linux arm64/macOS amd64 cross-builds.

The source fingerprint now uses tracked and nonignored untracked paths, excluding generated results and ignored Python caches. Local dirty packaging is accepted only with the explicit developer flag; require-clean verification rejects that artifact. Actual clean candidate packaging and native CI must pass before selecting a stable Transfer version. Stable publication must still run the exact-source CI/package/native gates and verify downloaded public assets before exposing website links. Release progress and verified run IDs belong in AGENTS.md.

The clean candidate 4e234ef2e9dcb4c942673a757ab701d5e7c41a49 passed CI 39391488194 and all five package/three native jobs in Release Transfer 39391730821, with publication skipped. The compatibility follow-up preserving checksum-verified other-product verification metadata passed separate re-review and twenty-two Python guards. Transfer 0.1.0 was then selected for the automatic stable gates. Public asset verification remains required before website download links change.
