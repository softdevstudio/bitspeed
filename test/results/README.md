# Test results

- latest/ holds the most recent run of scripts/record-results.sh. Each run replaces it; earlier runs are in git history.
- inspect-0.1.1-release/, transfer-0.1.0-release/, transfer-0.2.0-release/ and transfer-0.3.0-release/ hold the public verification for each published release.
- site-launch/ holds the website checks and the protected theme file hashes.

Numbers on bitspeed.org come from these folders.
